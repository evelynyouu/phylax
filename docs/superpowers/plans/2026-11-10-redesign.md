# Phylax Redesign Plan

Source: the author's brief of 2026-11-10 (pasted into the session), split into tasks. The brief is the spec.
Design source of truth: `design/` (README tokens, `pages/*.dc.html` mockups, `bouquet-engine.js`).

## Global Constraints

- Next.js 16 App Router, Cache Components on. No `export const dynamic`. Request-time work inside `<Suspense>` after `await connection()`. Read `node_modules/next/dist/docs/` before routes, layouts, data fetching. Middleware is `proxy.ts` in Next 16.
- Don't change extraction behavior. `npm test` and `npm run eval` keep passing.
- After each task: `npx tsc --noEmit`, `npm run lint`, `npm test`, `npm run build` all pass.
- No em dashes in UI copy. Never commit `.env.local`, `data/`, or tokens.
- Wire app pages to real data from `getDashboard()`. When a mockup number only exists in sample data, use the honest version and report it.
- Never mauve or sage as small text; use the working ink colors.
- Commit after each task on branch `redesign`; push; PR to main at the end listing what changed and what is left.

## Review Focus

1. Signed-out access: every `/app/*` page and every mutating API route rejects or redirects without a valid session cookie; a tampered or expired cookie is rejected.
2. Demo mode (`npm run demo`) still works end to end without Google credentials.
3. Calendar month boundaries: charges for any visible month (past or future, yearly and weekly cadences, Feb 29/31st clamping).
4. Manual cancellation hides future charges until a newer receipt arrives, and never hides one-off bills.
5. Three.js hero: renderer disposed on unmount, paused off screen, DPR capped at 2, WebGL failure fallback, reduced motion turns off motion and birds.

---

### Task 1: Design tokens and fonts
CSS variables for every color in design/README.md; Gloock and Hanken Grotesk via next/font/google; tabular numbers; visible focus ring; prefers-reduced-motion respected everywhere.

### Task 2: Shared components
Button (primary / ghost / danger), Chip, Tag, Field, MerchantMark (leaf corner, category color), AppShell (sidebar nav: Dashboard, Recurring, Calendar, Bills and deadlines; account and sign out at the bottom; stacks on mobile).

### Task 3: Auth
One user, local app. "Continue with Google" reuses the existing OAuth flow; add openid email profile scopes; httpOnly signed session cookie. Protect /app/* and mutating API routes; redirect to /signin when signed out. Keep gmail.readonly. Email/password form kept but marked "coming soon".

### Task 4: Data layer for the new pages
Category map (Streaming, Software and AI, Storage, Shopping, Learning, Other) keyed by merchant. Calendar charges for any month from cadence + next charge date, plus bill due dates. `paid` and `reminders` tables in lib/db.ts plus same-origin routes to mark paid / undo and toggle reminders. "I've cancelled it" stores a manual cancellation that hides future charges until a newer receipt arrives (tested). Cancel-link trust warning kept.

### Task 5: Routes and pages
/ (Main.dc.html), /signin, /signup (step 2 starts OAuth, step 3 shows real /api/sync progress), /app (Dashboard), /app/recurring, /app/calendar, /app/bills, /style.

### Task 6: Landing hero
Port design/bouquet-engine.js to components/Bouquet.tsx with the `three` package via next/dynamic ssr:false. Sticky full-width stage in a tall section; scroll fades text, moves camera in, grows bouquet to center, then enables drag-to-rotate and petal pruning with readout, savings counter, chips. Bluebirds every 5 to 12 s. Dispose on unmount, pause off screen (IntersectionObserver), DPR cap 2, WebGL fallback, reduced motion disables motion and birds. Petals mapped to sample subscriptions.

### Task 7: Polish
Every page at 1440px and 390px, keyboard-test main flows, contrast fixes with working colors.
